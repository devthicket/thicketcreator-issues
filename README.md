# Thicket Creator issues

Bug reports and feature requests for the [Thicket Creator](https://www.thicketcreator.com/) game creation studios:

| Label | Studio |
|---|---|
| `waystone` | Waystone: RPG Creation Studio |
| `anthill` | Anthill (in development) |
| `hedge` | Hedge (in development) |
| `lilypad` | Lilypad (in development) |
| `website` | thicketcreator.com |

This repository holds issues only; the studios' source is not here.

## Before you open an issue

- **Search first.** Someone may have reported it already; add a 👍 or your details to that issue instead.
- **One problem per issue.**
- **Questions and help** are quicker in the [Discord](https://discord.gg/phanxgames).
- **The language itself** (ThicketScript) has its own issues repo: [thicketscript-issues](https://github.com/devthicket/thicketscript-issues). Not sure which? File it here and we will move it.

## Opening an issue

Choose **New issue** and pick a template: **Bug report**, **Feature request** or **Website problem**. Tell us which
studio and version, what you did, what you expected and what happened. Screenshots and a small project that shows the
problem help a lot.
